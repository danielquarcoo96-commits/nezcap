NEZCAP MVP LANDING PAGE

Files:
- index.html       Main responsive landing page + CSS + JavaScript
- hero-model.jpg   Cropped hero/background image from the supplied reference
- nezcap-product.png  Exact supplied NezCap product image (unchanged)

HOW TO RUN:
1. Put all three files in the same folder.
2. Open index.html in VS Code with Live Server, or open it directly in a browser.

IMAGE REPLACEMENT:
- Hero image: replace hero-model.jpg
- Product image: replace nezcap-product.png
The HTML already points to these filenames.

CITY / AQI DATA:
The 10-city values are DEMO values for the MVP interface. They are not live readings.
To connect real AQI data later, replace the cityData object / updateAir() flow with
data from a real air-quality API through your backend.

CURRENT CITIES:
Cyberjaya, Putrajaya, Kuala Lumpur, Shah Alam, Petaling Jaya,
Johor Bahru, Penang, Ipoh, Malacca City, Kota Kinabalu.
